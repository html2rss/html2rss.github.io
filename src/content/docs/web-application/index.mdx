`html2rss-web` is the recommended product surface. Run the [Getting Started](/getting-started/) demo, create one feed from a page URL, then move to [Deployment](/web-application/deployment/) for production secrets and stable hosting.

## What you get

- Web UI for page-URL auto-source
- Access-controlled create API (`HTML2RSS_ACCESS_TOKEN`)
- Feed Directory catalog from your instance (`GET /api/v1/configs`)
- Optional custom YAML via `feeds.yml` mount
- OpenAPI at `/openapi.yaml`

The extraction engine is the [`html2rss`](https://github.com/html2rss/html2rss) gem.
